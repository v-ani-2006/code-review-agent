# CodePilot AI — Project Logo & Visual Branding Guidelines

## Logo Concept & Visual Identity

The **CodePilot AI** logo represents the synergy between deterministic static code compilation (AST syntax trees) and generative artificial intelligence reasoning (neural network nodes & flight navigation).

### Logo Dimensions & Formats:
* **Vector Master**: `assets/logo.svg` (Scalable vector graphic)
* **Standard Resolution**: `assets/logo.png` (512x512 PNG with transparent background)
* **Banner Resolution**: `assets/banner.png` (1280x640 PNG for GitHub social preview)
* **Favicon**: `assets/favicon.ico` (32x32 / 16x16 multi-resolution icon)

### Palette Tokens:
* **Primary Brand**: `#6366F1` (Indigo / Quantum Blue)
* **Secondary Brand**: `#8B5CF6` (Violet / AI Resonance)
* **Accent Cyber**: `#10B981` (Emerald / AST Conformance Pass)
* **Background Dark**: `#0F172A` (Slate 900)
* **Text High Contrast**: `#F8FAFC` (Slate 50)
